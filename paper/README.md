# Paper source

`root.tex` is the conference paper in the IEEE `ieeeconf` class (the class file is provided by the conference / Overleaf
template and is not stored here).

| File | Content |
|---|---|
| `root.tex` | Paper |
| `references_merlin.bib` | References added for the bilateral controller and the simulation study; the original references stay in `references.bib` |
| `figures/*.pdf` | Simulation figures, generated by `python3 experiments/bilateral_sim/paper_figures.py` |

To build on Overleaf, upload `root.tex`, `references_merlin.bib` and `figures/` into the existing project. The project
already contains `ieeeconf.cls`, `references.bib` and `images/` (setup photo, `tracking_plot.png`, `Para.jpeg`).

All simulation numbers in the text come from the committed results in `experiments/bilateral_sim/results/`
(`multi_seed.json`, `model_validation.json`, `torque/studies.json`); see `docs/EVALUATION_METHODOLOGY.md` for how
they were produced. The derivations of the stated results are in `docs/derivations/merlin_derivations.pdf`.
